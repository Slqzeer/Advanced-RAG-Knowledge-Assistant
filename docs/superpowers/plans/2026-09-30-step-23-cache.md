# Step 23 — Cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve a repeated question (exact layer) and, only if a pre-registered rule allows it, a paraphrase of one (semantic layer) from Redis 8, and publish the cache-hit latency and cost deltas.

**Architecture:** A new `app/generation/cache.py` wraps `answer_question()` without touching it. `cached_answer()` looks up a sha256 key over the normalised question, the history and every answer-shaping setting. On a miss with no history, it checks the nearest stored question in a Redis vector set, filtered to the same settings fingerprint. Otherwise it generates and stores the answer. Benchmarks keep calling `answer_question()` directly, so they bypass the cache by construction. A hand-written 83-pair fixture and an offline cosine sweep decide whether `CACHE_SEMANTIC_THRESHOLD` is ever set.

**Tech Stack:** Python 3.12, `uv`, `redis` (redis-py, new), Redis 8 vector sets (`VADD`/`VSIM`/`VREM`), `pydantic` / `pydantic-settings`, `pytest`, `ruff`, `mypy --strict`.

**Spec:** [`docs/superpowers/specs/2026-09-30-cache-design.md`](../specs/2026-09-30-cache-design.md). Read it before Task 1, especially "Facts this design is built on" and the follow-up assumption, which must be quoted verbatim wherever it appears.

## Global Constraints

- **Branch:** `step-23-cache`, cut from `main`.
- **Quality gates before every commit, all four:**
  `uv run ruff check . && uv run ruff format --check . && uv run mypy app && uv run pytest`
- **`mypy` is strict on `app/`.** Every new function fully annotated. If strict mypy reports `type-arg` on `Redis`, annotate it as `"Redis[bytes]"`. The client is always built with `decode_responses=False`.
- **Unit tests use no network, no key, no spend.** The seams are `client=`, `embedder=`, `answerer=` and `settings=`. `Settings(_env_file=None, ...)` in every test, as `tests/test_core_config.py` does.

- **`ruff` line length 100**, rules `B E F I SIM UP`.
- **One new dependency: `redis`.** It's added with `uv lock` in the same commit.
- **`data/eval/questions.jsonl` is frozen.**
- **Settings default to today's behaviour:** `redis_url = ""` means no cache and no connection, and `cache_semantic_threshold = None` means the semantic layer is off. The threshold is set only in Task 6, only if Rule S passes, and in the commit that carries the number.
- **The fixture is committed alone, before `scripts/benchmark_cache.py` exists** (Task 5 before Task 6), and only after the user has reviewed it.
- **Pre-registered rules are not renegotiated mid-step.** Rule S and Rule E are in the spec under "Measurement", with the refinement recorded in Task 6.
- **`.env.example` and the README are in French.** Code comments and docstrings are in English.
- **The follow-up assumption wording is fixed**, and the `ponytail:` comment, spec, README and roadmap all use it:
  > Follow-ups get exact lookups only. **Assumption, not measurement:** a semantic hit on a follow-up needs the history resolved first (one LLM call, ~1-2 s) before we know whether it hits, and we expect repeated follow-ups to be rare. - **Arms:** run one at a time, with `set -o pipefail` and `python -u`. Check `data/eval/cache.jsonl` for an existing label first, because a repeated `cache-cold` arm bills twice.

## Review Focus

1. **A setting changed between two runs** (for example `COMPRESS_CANDIDATES=30` in `.env`) must miss, never serve the old answer. Pinned by the parametrized fingerprint test in Task 2.
2. **Redis down, or a stale container on the port**: `ask.py` still answers, prints one warning, and loses at most ~200 ms. Pinned by the dead-Redis test in Task 3.
3. **The embedding model changes the vector dimension** (`VADD` into a 1536-dim set with a 3072-dim vector raises `ResponseError`): the answer still comes back, with a warning. Pinned by `test_a_wrong_dimension_vector_warns_instead_of_failing` in Task 3.
4. **A paraphrase whose nearest stored question is a *different* anchor**: Redis serves that other anchor's answer, which is a false hit the pair-wise sweep would not see. Pinned by the nearest-neighbour sweep in Task 6 and the pair-for-pair check in Task 7's semantic arm.
5. **An answer stored under an older `Answer` schema** (a field added at step 24): it's a miss, the key is deleted, and nothing crashes. Pinned by `test_an_undecodable_entry_is_a_miss_and_is_deleted` in Task 3.

`app/generation/cache.py`:

```python
"""Answer the same question twice for the price of once.

    cached_answer -> exact key -> nearest stored question -> answer_question -> store

A wrapper, not a pipeline stage: answer_question() never learns a cache exists,
and every benchmark calls answer_question() directly, so no measurement can be
served a stored answer. Step 22 learned why that matters from a gateway's cache.
"""

import hashlib
import json
from collections.abc import Mapping, Sequence
from typing import Any

from app.core.config import Settings

# Settings that cannot change an answer. A denylist, not an allowlist: a setting
# added later changes the key by default, so forgetting one costs a miss, never a
# stale answer.
_UNKEYED = frozenset(
    {"qdrant_url", "redis_url", "cache_ttl_s", "cache_semantic_threshold", "corpus_dir"}
)


def keyed_settings(settings: Settings) -> dict[str, Any]:
    """Every setting that can shape an answer: secrets, local paths and the judge excluded."""
    return {
        name: value
        for name, value in settings.model_dump(mode="json").items()
        if name not in _UNKEYED
        and not name.endswith(("_api_key", "_path"))
        and not name.startswith("judge_")
    }


def _digest(payload: Mapping[str, Any]) -> str:
    # default=str: a filters mapping may hold tuples or enums, and a key that
    # cannot be built must not be the reason an answer fails.
    canonical = json.dumps(payload, sort_keys=True, separators=(",", ":"), default=str)
    return hashlib.sha256(canonical.encode("utf-8")).hexdigest()


def fingerprint(settings: Settings, kwargs: Mapping[str, Any]) -> str:
    """Everything that shapes an answer except the question: a paraphrase may only
    hit an answer produced under the same fingerprint.

    kwargs are keyed as passed, not resolved against settings, so ``top_k=None``
    and ``top_k=5`` are two keys for one answer. That costs a miss, never a stale
    hit, and resolving them here would duplicate answer_question()'s defaults.
    """
    return _digest({"settings": keyed_settings(settings), "kwargs": dict(kwargs)})


def cache_key(
    question: str,
    history: Sequence[Mapping[str, str]] | None,
    settings: Settings,
    kwargs: Mapping[str, Any],
) -> str:
    """The exact-layer key. Whitespace collapsed, case kept: ``Depends`` and
    ``depends`` are different things in these docs, and paraphrase is the
    semantic layer's job. History truncated exactly as contextualize() does."""
    turns = [dict(turn) for turn in list(history or [])[-settings.history_turns :]]
    return _digest(
        {
            "question": " ".join(question.split()),
            "history": turns,
            "fp": fingerprint(settings, kwargs),
        }
    )
```

Note `list([])[-n:]` is `[]` for any `n`, so `None` and `[]` key identically, as the test requires.

```python
QVEC = PREFIX + "qvec"
# A dead Redis costs at most this per call, never a hang.
TIMEOUT_S = 0.2

Embedder = Callable[[str], list[float]]


def connect(settings: Settings) -> Redis:
    return Redis.from_url(
        settings.redis_url, socket_timeout=TIMEOUT_S, socket_connect_timeout=TIMEOUT_S
    )


def similarity_floor(threshold: float) -> float:
    """The VSIM score a cosine threshold maps to. VSIM scores (1 + cosine) / 2:
    1 identical, 0.5 orthogonal, 0 opposite. Pinned by a requires_redis test."""
    return (1 + threshold) / 2


def _fp32(vector: Sequence[float]) -> bytes:
    return struct.pack(f"<{len(vector)}f", *vector)


def _text(value: bytes | str) -> str:
    return value.decode() if isinstance(value, bytes) else value


def _pairs(reply: Any) -> list[tuple[str, float]]:
    # redis-py returns VSIM ... WITHSCORES as a flat [element, score, ...] list
    # (checked against Redis 8 at step 23).
    return [(_text(reply[i]), float(reply[i + 1])) for i in range(0, len(reply or []), 2)]


def _stored(client: Redis, key: str) -> Answer | None:
    raw = client.get(ANSWER_PREFIX + key)
    if raw is None:
        return None
    try:
        return Answer.model_validate_json(raw)
    except ValidationError:
        # Written under an older Answer schema: a miss, and not one to repeat.
        client.delete(ANSWER_PREFIX + key)
        return None


def _nearest(client: Redis, vector: Sequence[float], fp: str, threshold: float) -> Answer | None:
    reply = client.execute_command(
        "VSIM", QVEC, "FP32", _fp32(vector), "WITHSCORES", "COUNT", 1,
        "FILTER", f'.fp == "{fp}"',
    )
    pairs = _pairs(reply)
    if not pairs or pairs[0][1] < similarity_floor(threshold):
        return None
    element = pairs[0][0]
    hit = _stored(client, element)
    if hit is None:
        # The answer expired and its vector did not: vector-set elements have no
        # TTL of their own, so the lookup that finds one cleans it up.
        client.execute_command("VREM", QVEC, element)
    return hit


def _warned(answer: Answer, message: str) -> Answer:
    return answer.model_copy(update={"warnings": [*answer.warnings, message]})


def cached_answer(
    question: str,
    *,
    history: Sequence[Mapping[str, str]] | None = None,
    settings: Settings | None = None,
    client: Redis | None = None,
    embedder: Embedder | None = None,
    answerer: Callable[..., Answer] = answer_question,
    **kwargs: Any,
) -> Answer:
    """answer_question(), served from Redis when the same question, or a close
    enough paraphrase of it, was answered under the same settings.

    A hit returns one stored sample, frozen: at temperature 0 this generator
    still differs on identical input, and a cache is how that stops mattering.
    Refusals are never stored. Any Redis failure is a warning, never an error.
    """
    settings = settings or get_settings()
    if client is None and not settings.redis_url:
        return answerer(question, history=history, settings=settings, **kwargs)

    started = time.perf_counter()
    client = client or connect(settings)

    def vector() -> list[float]:
        # Built only when needed: an exact hit, or a dead Redis, never opens the
        # sqlite embedding cache.
        return (embedder or default_embedder(settings))(question)

    key = cache_key(question, history, settings, kwargs)
    fp = fingerprint(settings, kwargs)
    # ponytail: follow-ups get exact lookups only. Assumption, not measurement: a
    # semantic hit on a follow-up needs the history resolved first (one LLM call,
    # ~1-2 s) before we know whether it hits, and we expect repeated follow-ups
    # to be rare. There is no traffic to measure that on yet; step 24's per-query
    # trace can count it.
    indexable = not history
    threshold = settings.cache_semantic_threshold

    try:
        hit, layer = _stored(client, key), "exact"
        if hit is None and indexable and threshold is not None:
            hit, layer = _nearest(client, vector(), fp, threshold), "semantic"
    except RedisError as error:
        answer = answerer(question, history=history, settings=settings, **kwargs)
        return _warned(answer, f"cache lookup failed, answered without it: {error}")
    if hit is not None:
        elapsed = (time.perf_counter() - started) * 1000
        return hit.model_copy(update={"cache": layer, "latency_ms": elapsed})

    answer = answerer(question, history=history, settings=settings, **kwargs)
    if answer.refusal is not None:
        return answer  # a refusal must not outlive the re-index that fixes it
    try:
        client.set(ANSWER_PREFIX + key, answer.model_dump_json(), ex=settings.cache_ttl_s)
        if indexable:
            # Indexed whether or not the semantic layer is on, so turning it on
            # later starts from a warm set rather than an empty one.
            client.execute_command(
                "VADD", QVEC, "FP32", _fp32(vector()), key,
                "NOQUANT", "SETATTR", json.dumps({"fp": fp}),
            )
    except RedisError as error:
        return _warned(answer, f"cache store failed: {error}")
    return answer


def clear_cache(client: Redis | None = None, *, settings: Settings | None = None) -> int:
    """Delete every cached answer and the vector set; nothing outside the prefix.
    Returns how many keys were deleted. No Redis configured is zero, not an error."""
    settings = settings or get_settings()
    if client is None:
        if not settings.redis_url:
            return 0
        client = connect(settings)
    keys = [QVEC, *client.scan_iter(match=ANSWER_PREFIX + "*", count=500)]
    return int(client.delete(*keys))
```

```python
class CachePair(EvalQuestion):
    """A probe for step 23's semantic cache and the question it may or may not hit.

    ``question`` is the probe, and ``relevant_document_ids`` is *its own* ground
    truth. That is what makes the fixture's one rule checkable: a paraphrase keeps
    its anchor's documents, a near-miss does not keep both its documents and its
    sections. The anchor's text is never copied here; ``anchor_id`` points into
    the frozen question set.
    """

    anchor_id: str = Field(min_length=1)
    kind: Literal["paraphrase", "near_miss", "unanswerable"]

    @model_validator(mode="after")
    def _check_kind(self) -> "CachePair":
        if self.kind == "unanswerable" and self.category != "unanswerable":
            raise ValueError("an unanswerable pair must have category 'unanswerable'")
        if self.kind == "paraphrase" and self.category == "unanswerable":
            raise ValueError("a paraphrase of an answerable question is never unanswerable")
        return self
```

A `near_miss` may itself be `unanswerable` (a question the corpus cannot answer that looks like one it can). A `paraphrase` never is, and an `unanswerable` pair always is.

**The refinement, recorded before any cosine is read.** Redis compares a probe against **every** stored anchor, not only its own. So the sweep scores each probe by its **nearest anchor among the 38**:
- A **false hit** at threshold *t* is either a must-miss probe (`near_miss` or `unanswerable`) whose nearest cosine is ≥ *t*, or a paraphrase whose nearest anchor is **not** its own and whose nearest cosine is ≥ *t*.
- A **paraphrase hit** is one whose nearest anchor is its own, with cosine ≥ *t*.
- **Candidate threshold** = the highest false-hit cosine + 0.02.

This means clause 1 of Rule S (0 false hits) holds **on this fixture by construction**. The threshold is placed above every would-be false hit. The rule's real content is clause 2 (≥ 19 of 38 paraphrases still hit). Clause 1 gets tested out of sample in Task 7's semantic arm, through Redis's own search. The spec already records this.

```python
from pathlib import Path
from typing import Any

def cosine(a: list[float], b: list[float]) -> float:
    dot = sum(x * y for x, y in zip(a, b, strict=True))
    norm = (sum(x * x for x in a) * sum(y * y for y in b)) ** 0.5
    return dot / norm


def sweep() -> dict[str, Any]:

    anchor_vectors = {a.question_id: embed(a.question) for a in anchors()}
    per_probe = []
    for pair in pairs():
        vector = embed(pair.question)
        scores = {aid: cosine(vector, av) for aid, av in anchor_vectors.items()}
        nearest = max(scores, key=scores.__getitem__)
        per_probe.append(
            {
                "id": pair.question_id,
                "kind": pair.kind,
                "anchor_id": pair.anchor_id,
                "own_cosine": scores[pair.anchor_id],
                "nearest_id": nearest,
                "nearest_cosine": scores[nearest],
            }
        )
    would_be_false = [
        p["nearest_cosine"]
        for p in per_probe
        if p["kind"] != "paraphrase" or p["nearest_id"] != p["anchor_id"]
    ]
    threshold = max(would_be_false) + MARGIN
    false_hits = sum(1 for c in would_be_false if c >= threshold)
    paraphrase_hits = sum(
        1
        for p in per_probe
        if p["kind"] == "paraphrase"
        and p["nearest_id"] == p["anchor_id"]
        and p["nearest_cosine"] >= threshold
    )
    return {
        "candidate_threshold": round(threshold, 4),
        "false_hits": false_hits,
        "must_miss": len(would_be_false),
        "paraphrase_hits": paraphrase_hits,
        "rule_s": false_hits == 0 and paraphrase_hits >= MIN_PARAPHRASE_HITS,
        "per_probe": per_probe,
    }


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--sweep", action="store_true")
    parser.add_argument("--no-save", action="store_true", help="print only, append nothing")
    args = parser.parse_args()
    if not args.sweep:
        parser.error("choose --sweep")

    result = sweep()
    kinds = ("paraphrase", "near_miss", "unanswerable")
    for kind in kinds:
        own = sorted(p["own_cosine"] for p in result["per_probe"] if p["kind"] == kind)
        p50, p95 = percentiles(own)
        print(f"{kind:<13} own-anchor cosine  min {own[0]:.3f}  p50 {p50:.3f}  p95 {p95:.3f}  max {own[-1]:.3f}")
    wrong = [p["id"] for p in result["per_probe"] if p["kind"] == "paraphrase" and p["nearest_id"] != p["anchor_id"]]
    print(f"paraphrases nearer another anchor: {len(wrong)} {wrong}")
    print(f"candidate threshold {result['candidate_threshold']:.4f}")
    print(f"false hits          {result['false_hits']} of {result['must_miss']}")
    print(f"paraphrase hits     {result['paraphrase_hits']} of 38 (need {MIN_PARAPHRASE_HITS})")
    print(f"Rule S              {'PASS' if result['rule_s'] else 'FAIL'}")

    row = {
        "label": "cache-sweep",
        "timestamp": datetime.now(UTC).isoformat(),
        "git_commit": git_commit(),
        "config": {"embedding_model": get_settings().embedding_model, "margin": MARGIN},
        **result,
    }
    if not args.no_save:
        with HISTORY.open("a", encoding="utf-8") as history:
            history.write(json.dumps(row, ensure_ascii=False) + "\n")
        print(f"\nappended to {HISTORY}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
import time

from app.generation.answer import answer_question
from app.generation.cache import cached_answer, clear_cache, connect
from app.models.answers import Answer, RetrievalStats


def _no_spend(question: str, **_: Any) -> Answer:
    """The semantic arm's answerer: a miss must not cost a generation call, and a
    refusal is never stored, so a miss leaves the cache exactly as it found it."""
    return Answer(
        answer="(miss)",
        retrieval=RetrievalStats(retrieved=0, used=0, dropped=0),
        latency_ms=0.0,
        model="none",
        refusal="no_context",
    )


def arm(name: str, price_in: float | None, price_out: float | None) -> dict[str, Any]:
    settings = get_settings()
    if not settings.redis_url:
        raise SystemExit("REDIS_URL is empty; the arms measure the cache")
    client = connect(settings)
    if name == "cold":
        clear_cache(client)
    if name == "semantic":
        if settings.cache_semantic_threshold is None:
            raise SystemExit("Rule S did not pass; there is no semantic arm to run")
        probes = [(p.question_id, p.question, p.kind, p.anchor_id) for p in pairs()]
        answerer = _no_spend
    else:
        probes = [(a.question_id, a.question, "anchor", a.question_id) for a in anchors()]
        answerer = answer_question

    rows = []
    for probe_id, text, kind, anchor_id in probes:
        started = time.perf_counter()
        answer = cached_answer(text, client=client, answerer=answerer)
        rows.append(
            {
                "id": probe_id,
                "kind": kind,
                "anchor_id": anchor_id,
                "cache": answer.cache,
                "answer": answer.answer,
                "wall_ms": (time.perf_counter() - started) * 1000,
                "prompt_tokens": answer.usage.get("prompt_tokens", 0),
                "completion_tokens": answer.usage.get("completion_tokens", 0),
                "refusal": answer.refusal,
                "warnings": answer.warnings,
            }
        )
        print(f"{probe_id:<10} {kind:<13} {answer.cache or 'miss':<9} {rows[-1]['wall_ms']:7.0f} ms")

    hits = [r for r in rows if r["cache"]]
    misses = [r for r in rows if not r["cache"]]
    hit_p50, hit_p95 = percentiles([r["wall_ms"] for r in hits])
    miss_p50, miss_p95 = percentiles([r["wall_ms"] for r in misses])
    tokens_in = sum(r["prompt_tokens"] for r in misses)
    tokens_out = sum(r["completion_tokens"] for r in misses)
    usd = (
        (tokens_in * price_in + tokens_out * price_out) / 1e6
        if price_in is not None and price_out is not None
        else None
    )
    return {
        "hits": len(hits),
        "misses": len(misses),
        "hit_p50_ms": hit_p50,
        "hit_p95_ms": hit_p95,
        "miss_p50_ms": miss_p50,
        "miss_p95_ms": miss_p95,
        "prompt_tokens": tokens_in,
        "completion_tokens": tokens_out,
        "usd_at_list_price": usd,
        "per_probe": rows,
    }
```

```python
def verdicts(name: str, row: dict[str, Any]) -> dict[str, Any]:
    past = [json.loads(line) for line in HISTORY.read_text(encoding="utf-8").splitlines()]
    if name == "exact":
        cold = next(r for r in reversed(past) if r["label"] == "cache-cold")
        stored = {r["id"]: r["answer"] for r in cold["per_probe"] if r["refusal"] is None}
        served = {r["id"]: r["answer"] for r in row["per_probe"] if r["cache"] == "exact"}
        return {
            # Every answer cold stored comes back, byte-identical; refusals were
            # never stored, so they are misses by design, not failures.
            "rule_e": served == stored and row["hit_p50_ms"] < 50,
            "stored": len(stored),
            "cold_refusals": len(cold["per_probe"]) - len(stored),
        }
    if name == "semantic":
        swept = next(r for r in reversed(past) if r["label"] == "cache-sweep")
        cold = next(r for r in reversed(past) if r["label"] == "cache-cold")
        # An anchor cold refused was never stored, so its paraphrase cannot hit.
        stored = {r["id"] for r in cold["per_probe"] if r["refusal"] is None}
        t = swept["candidate_threshold"]
        predicted = {
            p["id"]
            for p in swept["per_probe"]
            if p["kind"] == "paraphrase"
            and p["anchor_id"] in stored
            and p["nearest_id"] == p["anchor_id"]
            and p["nearest_cosine"] >= t
        }
        served = {r["id"] for r in row["per_probe"] if r["cache"] == "semantic"}
        false_hits = [
            r["id"] for r in row["per_probe"] if r["cache"] and r["kind"] != "paraphrase"
        ]
        # A paraphrase served its own anchor's answer iff the answer text matches cold's.
        by_anchor = {r["id"]: r["answer"] for r in cold["per_probe"]}
        wrong_anchor = [
            r["id"]
            for r in row["per_probe"]
            if r["kind"] == "paraphrase" and r["cache"] and r["answer"] != by_anchor[r["anchor_id"]]
        ]
        return {
            "semantic_check": served == predicted and not false_hits and not wrong_anchor,
            "predicted_not_served": sorted(predicted - served),
            "served_not_predicted": sorted(served - predicted),
            "false_hits": false_hits,
            "wrong_anchor": wrong_anchor,
        }
    return {}
```
